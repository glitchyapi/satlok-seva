Publish a web (in-app) update

Pick the app/assets/web folder from your machine. Only files whose SHA-256 changed are uploaded — devices download only those changed files.

Publish a native APK (shell) update

Creates a GitHub Release, uploads the APK as asset, and points the manifest at it. Apps with an older shell show the “install APK” update screen.

Push a notice to all devices

On next app open every device shows an in-app banner + system notification.

File mirrors (HeOnlyFiles / any direct-link host)

Upload the changed files yourself to any host that gives direct download links, then paste one line per file: path URL. The app tries mirrors first, then the GitHub copy, and verifies SHA-256 of every file.
